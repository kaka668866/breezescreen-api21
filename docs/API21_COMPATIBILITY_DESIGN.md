# BreezeScreen API21 独立兼容实现设计

## 产品定位

`BreezeScreen API21` 是面向 Android 5.0（API 21）电视与盒子的独立兼容客户端。它参照 myDV 对外呈现的电视端导航、播放和全屏交互，但不复制未公开源码、不调用或模拟私有签名接口，也不自动化验证码或登录流程。

## 技术路线

| 模块 | 实现方案 | API 21 考量 |
|---|---|---|
| 内容呈现 | 系统 `WebView` 加载 `https://www.douyin.com/` | WebView、JavaScript、DOM Storage 均可在 API 21 使用 |
| 播放控制 | 通过通用 HTML5 `<video>` 元素执行播放/暂停与网页滚动 | 不依赖 Compose、Media3 或高版本播放器 API |
| TV 输入 | Activity 拦截方向、确认、菜单、返回和媒体播放键 | 使用 API 21 已有的 `KeyEvent` 常量 |
| 登录会话 | WebView 正常 Cookie 持久化；仅提供本机清除操作 | 不读取、不显示、不上传 Cookie 内容 |
| 大屏体验 | 横屏、沉浸式、硬件加速、可呼出的原生控制栏 | 使用旧版系统 UI flags，避免 API 23+ 专属能力 |

## 交互映射

| 遥控器按键 | 行为 |
|---|---|
| 上/下 | 按页滚动网页内容 |
| 左/右 | 小幅横向滚动或在内容区域移动 |
| 确认 / 播放暂停 | 播放或暂停当前可见 HTML5 视频 |
| 菜单 / 设置 | 显示或隐藏原生控制栏 |
| 返回 | 首先退出网页全屏；随后打开控制栏；控制栏中的“退出”完成离开应用 |

## 不纳入范围

不实现私有 API 签名、设备指纹伪装、验证码绕过、自动填写账号 Cookie、流媒体资源抓取或对平台请求的规避性拦截。若官方网页因自身策略改变而无法在 WebView 中正常工作，应用将显示加载错误并保留刷新、返回主页和清除本机会话的恢复操作。
